#  Project Requirements (requirements.txt) - Interpretable Hybrid Credit
#  Scoring for Thin-File and Underbanked Populations
#
#  This file pins the complete scientific-computing dependency set of
#  "Interpretable hybrid credit scoring for thin-file and underbanked
#  populations: A fairness-aware residual learning framework with evidence
#  from East African financial inclusion data" by Belise Kanziga,
#  Yae U. Gaba and Olivier Kanamugire (2026). It delivers an auditable,
#  fair and interpretable machine-learning credit-decisioning pipeline that
#  simultaneously preserves predictive accuracy, satisfies regulator-visible
#  explanation requirements, and proactively prevents protected subgroups
#  from being concealed within opaque model regions of a hybrid scorecard.
#
#  Core Methodological Components:
#  * Weight-of-Evidence scorecard baseline (logistic regression, L2, balanced)
#  * Raw-response residual learning via shallow gradient-boosted regression trees
#  * Probability-scale interpretability ratio rho(x) and the three-region partition
#  * Adaptive ensemble weighting alpha*(x) from Bernoulli-variance uncertainty
#  * Platt calibration with Expected Calibration Error and reliability diagnostics
#  * Fairness audit at interpretability-region granularity (routing rate,
#    disparate-impact ratio, equalized-odds difference, four-fifths reference)
#  * Stratified paired-bootstrap confidence intervals and DeLong z-tests
#  * TreeSHAP attribution and bootstrap stability screening on the residual branch
#  * Thin-file segmentation and pre-registered hypothesis testing
#  * Alternating-minimization joint-optimization fixed-point scheme
#  * Robustness analyses (threshold, LightGBM and reference-group sensitivity)
#  * Taiwan Credit Default continuity benchmark and Task 1-23 orchestration
#
#  Technical Implementation Features:
#  * Training-only frozen statistics (imputation, winsorization, binning,
#    WoE, one-hot, adaptive weights, Platt parameters) with a hard test barrier
#  * Deterministic seeding, SHA-256 frame digests and JSON checkpointing
#  * State-dictionary pipeline with per-callable verification and fidelity
#    diagnostics against the manuscript headline results
#  * CPU-only reproducible end-to-end execution (five minutes or less)
#
#  Paper Reference:
#  Kanziga, B., Gaba, Y. U., & Kanamugire, O. (2026). Interpretable hybrid
#  credit scoring for thin-file and underbanked populations: A fairness-aware
#  residual learning framework with evidence from East African financial
#  inclusion data. arXiv preprint arXiv:2608.26837.
